Hotel Billing System in C

A mini project developed in C for managing hotel orders, calculating bills, and handling payment options.

Features

* Breakfast menu
* Tea, coffee, and milk menu
* Quantity-based billing
* Automatic total bill calculation
* Cash, UPI, and card payment options
* Exit option

Technologies Used

* C Programming

C Concepts Used

* while loop
* switch-case
* if statements
* scanf() and printf()
* goto
* Arithmetic operations

Project Output

Output screenshots are included in this repository to demonstrate the working of the Hotel Billing System.

Learning

This mini project helped me practice C programming concepts and understand how menu-driven programs work.
